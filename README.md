# 안전미어캣 프로 — PWA 배포 패키지

이 폴더 안의 파일 전체를 **그대로, 같은 폴더 구조 그대로** 정적 웹호스팅(Netlify, Vercel, GitHub Pages, 또는 회사 자체 웹서버 등 아무 곳)에 올리면 됩니다.

## 포함된 파일
- `index.html` — 앱 본체 (v5.18, 이번 세션의 모든 수정사항 반영: 동의 게이트, 12개 모듈 수정 동기화, 첨부파일 업로드 UI 등)
- `manifest.json` — PWA 설정(앱 이름, 아이콘, 설치 시 표시 방식)
- `sw.js` — 서비스워커(오프라인 캐싱). **CACHE_VERSION을 `v5.18`로 올려뒀습니다** — 이전에 설치된 사용자도 다음 접속 시 최신 버전을 받습니다.
- `icon-*.png`, `apple-touch-icon.png`, `favicon-32.png` — 앱 아이콘

## 배포 후 확인할 것
1. 브라우저로 접속해서 정상적으로 뜨는지 확인
2. 모바일에서 "홈 화면에 추가"(안드로이드 Chrome) 또는 "홈 화면에 추가"(iOS Safari)로 설치되는지 확인
3. 설정 화면에서 서버 주소(`safety-meerkat-server`를 배포한 주소)를 입력하고 로그인이 되는지 확인
4. **파일명은 반드시 `index.html`을 유지하세요** — `manifest.json`의 `start_url`이 `./index.html`을 가리키고 있어서, 파일명을 바꾸면 PWA 설치가 깨집니다.

## 서버와의 관계
이 폴더(PWA/프론트엔드)와 `safety-meerkat-server`(백엔드 API)는 **서로 다른 곳에 배포되는 완전히 별개의 두 서비스**입니다. 프론트엔드는 정적 파일 호스팅에, 서버는 Node.js를 실행할 수 있는 곳(Railway, Fly.io 등)에 올려야 합니다. 자세한 서버 배포 순서는 `배포전_최종점검.md`를 참고하세요.
